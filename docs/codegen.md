# Code generation

`mpi-native-sys` carries a hand-written function set (`src/functions.rs`, `src/constants.rs`).
The panic stubs for the rest of the `ffi` surface (`src/stubs.rs`) are generated by
`mpi-native-sys/gen/gen_stubs.py` from the signature list of the retired `mpi-rt-sys` crate; see
the script's docstring. The output is checked in.
